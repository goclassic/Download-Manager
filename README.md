2026년 10월 13일 기존 다운로드 매니저의 문제를 해결한 Windows 10/11용 설치형 앱이 공개됐습니다.

이제 더 이상 java를 설치하실 필요가 없습니다.
당분간은 기존 java 설치하신 경우에도 그대로 사용 가능합니다.

새로워진 다운로드 매니저는 아래 기능이 추가됐습니다.
1) 파일 이어받기
2) 앨범별로 폴더 자동 생성
3) 대용량 파일에 대해 끊김 문제 해결
4) 대용량 파일 다운로드 속도 개선
5) 자동 업데이트

현재는 프로그램 인증이 되지 않아 Github에서만 다운로드 받으실 수 있으며, 보안 경고를 무시하셔야 설치하실 수 있습니다.
